## Verdict

At a rational projective target with trivial stabilizer, primitive height along
an injective-prefix orbit tends to infinity. This is stronger than the
unbounded-subsequence conclusion of `D2-O06`.

Let `g₀,g₁,…` be pairwise distinct group elements and choose a primitive pair
`vₙ` representing `gₙq`. If `vᵢ=vⱼ`, then `gᵢq=gⱼq`; the quotient
`gⱼ⁻¹gᵢ` fixes `q`. Trivial target stabilizer gives `gᵢ=gⱼ`, and prefix
injectivity gives `i=j`. Thus `n↦vₙ` is injective.

For each `H`, every `vₙ` of height at most `H` lies in the finite integer cube
`[-H,H]²`. The index sublevel

```text
{n | height(vₙ)≤H}
```

is therefore finite. Equivalently, for every `H` there is an index after which
all states have height greater than `H`. Lean packages this as

```text
Tendsto (n ↦ height(vₙ)) atTop atTop.
```

The path may descend and may return below `H` after an earlier escape. The
theorem proves only that every fixed sublevel has a last visit; it does not
compute that visit.

## Relation To The UCB Frontier

`D2-O05` exposed a bounded inverse cycle generated by a nonidentity target
stabilizer. `D2-O06` proved that every bounded infinite injective-prefix path
has the same algebraic source. `D2-O10`–`D2-O12` made bounded collision finite
and quantified height escape. `D2-O13` now removes infinite returns to any
fixed height cube after target-stabilizer triviality is known.

For a promised yes-instance, reachability from the trivial-stabilizer source
transports stabilizer triviality to the target. For a no-instance, a bounded
collision is already the `D2-O11` nonreachability certificate. The residual
case is therefore a proper height-escaping path without a computable
last-return bound or a classified escape direction.

finite integer cube back along that injection.
`primitiveHeight_tendsto_atTop_of_stabilizer_trivial` converts finite sublevels

The finite-family cardinal theorem from `D2-O12` now reuses the same canonical
state-injectivity lemma.

## Scope

The result assumes an injective prefix normal form and primitive representatives
of its target-orbit states. It proves no monotone one-step inequality. It does
not bound the last visit to a height cube in terms of the input matrices, select
a real or `p`-adic escape direction, or turn properness into termination.
