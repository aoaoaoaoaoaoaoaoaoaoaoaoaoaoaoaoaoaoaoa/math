# M₄(3) endomorphism-extendable fixed-boundary audit

**Date:** 30 August 2026

**Status:** every endomorphism-extendable positive fixed-boundary free-group instance is decidable

**Authorship:** GPT-5.6 Sol; elicited by @eternalism_4eva

**Target:** the injective/injective positive binary seam left by `M4-D04`

## Verdict

Let `α,β:S*→F(Δ)` be positive morphisms, with arbitrary fixed boundaries `a,b,c,d`. Suppose
there is an endomorphism `Φ:F(Δ)→F(Δ)` satisfying

```text
Φ(β(s))=α(s)
```

for every source letter. Then existence of a positive solution to

```text
a α(w)b=c β(w)d
```

is decidable. The same holds when `β` extends through `α`. Consequently every hard
injective/injective binary instance is mutually nonextendable.

In the subgroup generated by the two coordinate images and the four boundaries, neither image
of a hard instance can be a retract. In particular, neither image can be a free factor.

Identifying `F₂` with `β(F₂)` turns `α` into a partial endomorphism
`θ=α∘β⁻¹:β(F₂)→F(Δ)`. The surviving node is therefore positive-basis-constrained partial
twisted conjugacy for a nonextendable rank-two partial endomorphism, not unrestricted group
twisted conjugacy.

## Exact Reduction

Put

```text
p=bd⁻¹,       q=a⁻¹c,       y=β(w).
```

The boundary equation is equivalent to

```text
α(w)p=qβ(w).
```

The extension hypothesis gives `α(w)=Φ(β(w))=Φ(y)`, so

```text
a α(w)b=c β(w)d  ↔  p=Φ(y)⁻¹ q y.
```

This retains the same positive source word. It neither replaces `w` by an arbitrary group word
nor forgets the four fixed boundaries.

Suppose `y₀` is one group solution, and define

```text
K={h∈F(Δ):Φ(h)q=qh}=Fix(γ_q∘Φ),
```

where `γ_q(h)=q⁻¹hq`. Direct cancellation gives

```text
p=Φ(y)⁻¹qy  ↔  ∃h∈K:y=hy₀.
```

Thus the unrestricted group solutions are exactly the right coset `K y₀`. The positive problem
is the nonemptiness of

```text
β(S*) ∩ K y₀.
```

## Decision Layer

Ventura's endomorphism-twisted conjugacy algorithm computes either that no group solution
exists or a solution `y₀` and a free basis for `K`; its proof uses effective fixed subgroups of
free-group endomorphisms. The positive trace `β(S*)` is rational, as is the finitely generated
subgroup coset `K y₀`. Reduced-word automata decide whether these two rational subsets of a free
group intersect.

The extension promise is effectively recognizable. If `x_δ` denotes the unknown value of `Φ`
on each ambient basis letter, the conditions `Φ(β(s))=α(s)` are a finite system of equations in
the free group. Makanin's algorithm decides solvability. A positive answer plus ordinary
enumeration recovers explicit values for the `x_δ` and hence `Φ`.

For an injective binary `β`, any retraction onto `β(F₂)` extends `α∘β⁻¹`: compose that map with
the retraction. Hence a retract side is a special case. A free-factor side supplies a retraction
and is therefore decidable as well. These statements apply in the minimal instance subgroup,
not merely in an ambient presentation containing unused generators.
