## Results used

Affine automata use signed affine transitions and can recognize exclusive stochastic
languages with substantial state succinctness; the paper gives two-state families absent
from comparably bounded probabilistic and quantum models.

This is evidence that changing nonzero values can evade exact Hankel minimality. The
measurement applies an absolute-value normalization after the linear evolution, so the model
does not directly supply a rational series `λM_wγ` whose zero set can be inserted into
integer matrix mortality.
