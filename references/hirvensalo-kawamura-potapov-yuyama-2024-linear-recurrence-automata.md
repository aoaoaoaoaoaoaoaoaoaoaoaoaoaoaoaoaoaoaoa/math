## Results used

The paper defines linear recurrence automata and studies how reachability changes with the
number, depth, and control structure of the recurrences. It supplies the nearest published
vocabulary for the `M₃(2)` return family `Mₙ = VAⁿU`: a finite-dimensional matrix product
whose available transition matrix depends on an unbounded recurrence index.

The present project does not import a decision or undecidability theorem from this paper.
Its role is comparative: it prevents the new return problem from being misclassified as an
ordinary scalar Skolem instance and identifies adjacent recurrence-controlled reachability
models.
